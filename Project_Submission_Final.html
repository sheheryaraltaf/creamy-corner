3.2 Project Description

Creamy Corner is a Lahore-based ice cream stall that had no digital presence, managing all sales and customer records manually through pen-and-paper. Our platform delivers a full-stack e-commerce and business management system with two distinct sides.

On the customer side, shoppers can browse a catalog of 67 ice cream products across five categories — Kulfi, Cone, Sundae, Takeaway, and Specialty — search and filter by flavor or rating, add items to a persistent shopping cart, complete checkout with delivery details, and track their order status in real time. An order confirmation screen provides a one-tap WhatsApp button to notify the shop owner.

On the business side, the owner logs into a protected admin dashboard displaying live KPIs: total orders, total revenue, top-selling flavor, and average product rating, alongside visual charts for daily sales, popular flavors, and rating distributions. Dedicated modules for orders management (with CSV export), customer analytics with VIP classification, product inventory, and reviews are included. A dark/light mode toggle is available for comfort.

4.3 New Features (Final Submission)

✨ Feature 1 — Admin Login & Authentication NEW
A dedicated login page at /login with a split-screen design — branded Creamy Corner panel on the left and a secure email/password form on the right. Credentials are validated and a session token is stored in localStorage. The "Sign Out" button in the sidebar clears the session and returns to the login screen. This closes the critical security gap of an open admin dashboard.
✨ Feature 2 — Customer Order Tracking NEW
A public page at /track-order where customers enter their Order ID, phone number, or email to check the live status of their order. Results display a visual 4-step progress timeline (Pending → Processing → Shipped → Delivered), order items, total amount, and a WhatsApp support button. Accessible from both the shop header and the admin sidebar.
✨ Feature 3 — Dark / Light Mode Toggle NEW
A Sun/Moon icon button in the admin header allows toggling between light and dark themes. Implemented using next-themes with class-based strategy, persisted across sessions via localStorage. The entire UI — dashboard, charts, cards, sidebar — adapts seamlessly.
✨ Feature 4 — CSV Export for Orders NEW
An "Export CSV" button in the Orders Management table header allows the admin to download all current orders as a CSV file. The file includes Order ID, customer name, email, items, total amount (PKR), status, and date. This enables the business owner to do offline reporting in Excel.
✨ Feature 5 — WhatsApp Order Confirmation NEW
After a successful checkout, customers see a full-screen order confirmation card (instead of a redirect) showing their order ID, item count, and total. A prominent green "Confirm via WhatsApp" button opens WhatsApp with a pre-filled order summary message to the shop owner (0311-4782290), enabling instant order confirmation and reducing failed deliveries.

11. Challenges & Key Learnings

Top Technical Challenges

  • Real-time dashboard data aggregation: Calculating revenue and top-selling flavor required flattening a JSON items array across all orders. Solved by moving aggregation client-side in TypeScript using Array.reduce().
  • Cart persistence across App Router navigation: Server components caused cart state to reset. Solved by wrapping cart in a CartProvider client component at root layout.tsx with localStorage sync.
  • Order API atomicity: If order insert succeeded but stock deduction failed, the database would be inconsistent. Solved with manual rollback — order is deleted before returning the error.

What We Would Do Differently

We would design the database schema more carefully upfront — specifically using a relational order_items table instead of a JSON array, making analytics queries cleaner. We would also set up authentication from day one rather than leaving it as a future enhancement.
